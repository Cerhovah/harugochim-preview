## 기존 C23 하루고침 단일 모드 시연

[브라우저에서 사용하기 — 이중 모드 아님](https://cerhovah.github.io/harugochim-preview/)

[C23 단일 모드 APK 다운로드](https://github.com/Cerhovah/harugochim-preview/releases/download/v0.1.0-c23-demo.1/harugochim-c23-offline-preview.apk) · [파일 해시와 설치 주의사항](https://github.com/Cerhovah/harugochim-preview/releases/tag/v0.1.0-c23-demo.1)

이 저장소는 하루고침 C23 버전의 정적 웹 시연 파일과 별도 시험 APK 릴리스를 제공합니다. 원본 앱 저장소는 비공개로 유지합니다. 계정·동기화·외부 AI·결제는 이 시연 빌드에서 꺼져 있으며 개인 기록이나 개발 서버 인증 정보는 포함하지 않습니다. 웹에서 입력한 내용은 해당 브라우저의 로컬 저장소에 남습니다.

웹은 Android SQLite, 알림·캘린더 권한, OS 백업을 재현하지 않습니다. 별도 제공하는 APK도 Play 출시본이 아닌 자체 서명 체험판입니다. APK에는 앱의 네트워크 권한이 없지만 Android 시스템 백업은 기기 설정에 따라 외부 사본을 만들 수 있습니다. 정식 서비스/상용 출시 준비가 끝났다는 의미가 아닙니다.
